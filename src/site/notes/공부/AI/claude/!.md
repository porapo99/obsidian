`!`는 Bash Command를 사용할 수 있는 명령어입니다.
즉 `npm run dev`나 `pwd` 등의 명령어들을 클로드 명령어 창에 사용하여 이를 동작 시킬 수 있다는것 입니다.

대신 이게 그냥 명령어로 동작하는게 아니라 중요한점이 있습니다.
"Run the command AND give the output back to Claude as context"
명령어의 아웃풋이 컨텍스트로도 전달 된다는 것입니다.
이를 활용하는 예시로 빌드시 오류가 난다면 이 아웃풋이 클로드의 컨텍스트로도 전달되기때문에 자동으로 이를 점검하는 루프를 만든다던지 혹은 디버깅의 결과물을 알고 있으니 이를 분석해달라하기 편하다는 활용법이 있습니다.
