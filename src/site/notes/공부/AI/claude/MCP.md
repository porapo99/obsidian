claude code에서 외부 도구, 데이터와의통실을 돕는 프로토콜입니다.
AI 모델 자체는 텍스트 기반으로 주고 받는게 다지만 외부 프로그램에 접근하여 메세지를 보내고 데이터를 조회할때 각각 서로 다른 방법으로 이를 실행을 했어야했는데 이를 표준화하여 MCP라는 규격을 만들어서 사용하게 하는것

주요 구성 요소
1. MCP 호스트: 데이터에 액세스하기 위해 MCP를 사용하는 AI LLM 애플리케이션.
2. MCP 클라이언트: 호스트 애플리케이션 내부에서 MCP 서버와의 일대일 개별 연결을 유지하는 시스템.
3. MCP 서버: 표준화된 프로토콜을 통해 컨텍스트, 도구, 프롬프트 등 특정 기능과 정보 소스를 제공하며, 데이터와 기능을 MCP 클라이언트에 노출하는 프로그램.
4. 로컬 데이터 소스: 관련 정보를 포함하는 데이터베이스, 파일 및 로컬 서비스.
5. 원격 서비스: MCP 서버가 기능을 확장하기 위해 연결할 수 있는 외부 API 또는 서비스.
