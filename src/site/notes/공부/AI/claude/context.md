`/context`를 사용하면 claude가 어떠한 상태인지 보여줍니다.
모델의 이름을 알려줍니다
컨텍스트의 윈도우 사이즈를 알려줍니다
토큰의 사용량을 알려줍니다.
세부 사항
ㄴ 시스템 프롬프트
ㄴ 툴
ㄴ 메모리
ㄴ 스킬
ㄴ 메세지
ㄴ 빈공간
ㄴ autocompact buffer(우리가 물어본 것들이 남아있음 이게 어느정도차면 `/compact`를 진행함)

클로드의 환경을 알아 볼 수 있음 

`/clear`를 활용하여 `context`를 지워버릴 수 있음. 
클로드가 잘못된 방향으로 가거나 혹은 대화가 너무 깊어질 경우 , 환각증상이 생길때 메모리를 비우고 사용가능함.
`/compact`는 나눴던 대화를 압축하여 컨텍스트의 사용량을 줄일 수 있음 대화에 흐름을 저장하여 디버깅이 오래되거나 , 새로운 큰 문제가 생겼을때 기존의 요약본이 필요할때 필요하게 됩니다.
