Claude Code에는 반복 작업을 저장해두고 부르는 슬래시 커맨드가 있습니다. 대표적인 예가 `/simplify`인데, 방금 작업한(변경된) 파일들을 검토해서 코드 재사용 기회, 코드 품질 문제, 효율성 문제 세 가지를 찾아내고 지적으로 끝내지 않고 바로 수정까지 적용합니다.

`/simplify`는 별다른 지시 없이 단독으로 실행해도 됩니다. 최근 변경 파일을 자동으로 찾아서 리뷰 에이전트 3개(코드 재사용 / 코드 품질 / 효율성)를 병렬로 띄우고 겹치는 제안은 합쳐서 영향이 큰 것 위주로 우선순위를 정한 뒤 바로 반영합니다. 기능 구현이나 버그 수정을 끝낸 뒤, PR 올리기 직전 다듬는 단계에서 쓰기 좋습니다.

특정 관심사에 집중시키고 싶으면 뒤에 지시어를 붙이면 됩니다. `/simplify focus on memory efficiency`처럼 쓰면 리뷰어들이 메모리 관련 개선(할당 줄이기, 스트리밍 vs 버퍼링 등) 쪽으로 편향됩니다.
